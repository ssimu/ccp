# ccp

안녕하세요. ccp는 Claude Code 계정을 여러 개 쓰다가 지쳐서 만든 작은 도구예요.

회사 계정으로 한참 작업하다 한도가 딱 차버리면, 개인 계정으로 넘어가고 싶은데
`/logout` 하고 `/login` 하고 브라우저 인증하고… 하는 사이에 하던 대화 흐름이 끊기더라고요.
그래서 **계정을 바꿔도 대화는 그대로 이어지고, 어느 계정에 얼마나 남았는지 한눈에 보이게** 만들었습니다.

```
  Claude
  ── 지금 쓸 수 있음 ──────────────────────────────────
  ▸ 2) team       ← 추천 · 주간 62% 남음 · 리셋 2일 뒤
    0) 기본       주간 85% 남음 · 리셋 5일 뒤
  ── 지금 못 씀 · 세션만 차면 풀린다 ───────────────────
    1) personal   ⏳ 세션 소진 — 2시간12분 뒤 풀림
```

`ccp` 한 번 치면 이 화면이 뜨고, 엔터만 치면 지금 가장 여유 있는 계정으로 켜져요.
Codex CLI를 쓰고 계시면 그 계정들도 같은 화면에 함께 나옵니다.

## 시작하기

준비물은 세 개예요. Mac이나 Linux, zsh(Mac은 기본), 그리고 이미 쓰고 있는 Claude Code.
python3도 필요한데 Mac에는 들어 있어요.

터미널에 이 세 줄을 붙여 넣으세요.

```bash
git clone https://github.com/ssimu/ccp.git ~/projects/ccp
~/projects/ccp/install.sh
source ~/.zshrc
```

설치 스크립트는 `~/.zshrc`에 한 줄 넣고 설정 파일을 만들어 주는 게 전부라 몇 번 돌려도 괜찮아요.
로그인 정보는 어디에도 복사하지 않습니다. 그건 잠시 뒤에 직접 하실 거예요.

### 1. 내 계정 적기

`~/.config/ccp/profiles.tsv` 파일을 열어 보세요. 예시가 들어 있는데, 그걸 내 것으로 바꾸면 됩니다.
한 줄이 계정 하나고, 칸은 **탭**으로 나눕니다.

```
# 도구     이름        별칭   설명
claude     team        cct    회사 계정
claude     personal    ccm    개인 계정
```

- **이름**은 내가 알아볼 이름이면 뭐든 좋아요. 영문이 편합니다.
- **별칭**은 짧은 명령이에요. `cct`라고 치면 바로 그 계정으로 켜집니다. 귀찮으면 비워 두세요.
- 지금 쓰고 있는 `~/.claude` 계정은 적지 않아요. 언제나 0번 "기본"으로 나옵니다.

계정이 두 개든 다섯 개든, 줄 수만 맞추면 됩니다.

### 2. 만들기

```bash
ccp-sync
```

방금 적은 대로 계정 폴더를 만들어 줍니다.

### 3. 계정마다 한 번씩 로그인

```bash
ccp
```

메뉴에서 계정을 고르면 Claude Code가 그 계정으로 열려요. 처음이라 "로그인이 안 되어 있다"고 나올 텐데,
거기서 `/login` 하시면 됩니다. 계정 수만큼 반복하면 준비 끝이에요.

## 매일은 이렇게 써요

| 이렇게 치면 | 이렇게 됩니다 |
|---|---|
| `ccp` | 메뉴가 뜹니다. 방향키로 고르고 Enter. **그냥 Enter면 추천 계정** |
| `ccp team` 또는 `cct` | 그 계정으로 바로 |
| `ccp team -c` | 그 계정으로 **직전 대화를 이어서**. 한도 차서 옮길 때 이걸 씁니다 |
| `ccp-usage` | 메뉴 없이 남은 한도만 슬쩍 |
| `ccp-ls` | 계정마다 누가 로그인돼 있는지 |
| `ccp-new 이름 별칭` | 계정 하나 더 |

메뉴에서는 `↑↓`(또는 `j` `k`)로 움직이고, 숫자를 누르면 그 번호로 가고, `v`를 누르면 그래프와 표가 바뀌고, `q`로 나옵니다.

그리고 Claude Code 화면 맨 아래 상태줄에 지금 어느 계정인지, 한도가 얼마나 남았는지 늘 떠 있어요.

```
team:me@example.com │ 주간 ██░░░ 38% ↻2일3시간 │ 세션 █░░░░ 12% ↻1시간40분 │ Opus │ ~/proj │ ctx 12% │ git main
```

70%가 넘으면 노랗게, 90%가 넘으면 빨갛게 바뀌니 슬쩍 보기만 하면 됩니다.

## 자주 묻는 것들

**계정을 바꾸면 지금까지 대화가 날아가나요?**
아니에요. 대화 기록, 설정, 스킬은 모든 계정이 같은 걸 봐요. 로그인만 다릅니다.
그래서 한도가 차면 다른 계정으로 `ccp team -c` 해서 바로 이어갈 수 있어요. 이게 이 도구를 만든 이유예요.

**계정을 늘리거나 줄이고 싶어요.**
`profiles.tsv`에서 줄을 넣거나 빼고 `ccp-sync`. 뺀 계정의 폴더까지 정리하려면 `rm -rf ~/.claude-profiles/이름`.
그 계정의 로그인만 지워지고 대화 기록은 남습니다.

**저는 항상 `--dangerously-skip-permissions`로 켜는데요.**
`~/.config/ccp/config.zsh`를 열어 이 줄의 주석을 풀면 됩니다. 뜻을 아는 분만 켜세요.
```zsh
CCP_CLAUDE_ARGS=(--dangerously-skip-permissions)
```

**Codex도 쓰는데요.**
`codex` 명령이 있으면 메뉴에 자동으로 함께 나와요. Codex 계정을 여러 개 두고 싶으면
`profiles.tsv`에 도구 칸을 `codex`로 적으세요. 예: `codex	work	cxw	회사 워크스페이스`

**메뉴가 뜨는 데 몇 초 걸려요.**
계정마다 "얼마 남았니" 물어보는 시간이에요. 계정당 3초쯤인데 동시에 물어봐서 전체도 그 정도예요.
모델을 부르는 게 아니라서 토큰은 안 듭니다.

**원래 쓰던 상태줄이 있어요.**
`install.sh --no-statusline`으로 설치하면 상태줄은 건드리지 않아요.

**새 계정에서 MCP 서버가 안 보여요.**
MCP 설정은 계정마다 따로 있어요. 그 계정으로 켠 상태에서 `claude mcp add --scope user …`를 한 번 더 해 주세요.

## 뭔가 안 될 때

- `ccp` 명령이 없다고 하면 → 새 터미널을 열거나 `source ~/.zshrc`
- 메뉴에 내 계정이 안 보이면 → `ccp-sync`를 안 돌린 거예요
- "미로그인"이라고 나오면 → `ccp 이름`으로 열고 `/login`
- 별칭이 안 먹으면 → `cp`처럼 이미 있는 명령과 겹치는 이름이에요. 터미널 켤 때 경고가 떠요. 다른 이름으로 바꿔 주세요
- 그래도 안 되면 → 이 저장소에 이슈 남겨 주세요. 어떤 명령을 쳤고 뭐라고 나왔는지 같이요
