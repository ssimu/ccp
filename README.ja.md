# ccp

複数の Claude Code アカウントを、ログアウト・ログインなしで切り替える zsh ツールです。

上限に達したアカウントから別のアカウントに移っても、**会話履歴・設定・スキルはそのまま引き継がれます**。
どのアカウントにどれだけ残っているかを一画面で確認できます。Codex CLI のアカウントも同じメニューに出ます。

```
  Claude
  ── 今使える ─────────────────────────────────────────
  ▸ 2) team       ← おすすめ · 週間 62% 残り · 2日後にリセット
    0) 기본       週間 85% 残り · 5日後にリセット
  ── 今は使えない · セッション枠が空けば復活 ───────────
    1) personal   ⏳ セッション上限 — 2時間12分後に復活
```

`ccp` と打つとこの画面が出ます。Enter だけ押すと、今いちばん余裕のあるアカウントで起動します。

## はじめ方

必要なもの: macOS または Linux、zsh（macOS は標準）、python3（macOS に同梱）、インストール済みの Claude Code。

ターミナルにこの三行を貼り付けてください。

```bash
git clone https://github.com/ssimu/ccp.git ~/projects/ccp
~/projects/ccp/install.sh
source ~/.zshrc
```

インストーラーは `~/.zshrc` に一行追加して設定ファイルを作るだけです。何度実行しても安全です。
ログイン情報はどこにもコピーしません。ログインは手順 3 で自分で行います。

### 1. 自分のアカウントを書く

`~/.config/ccp/profiles.tsv` を開くと例が入っています。自分のアカウントに書き換えます。
1行が1アカウント、列は **タブ** で区切ります。

```
# ツール     名前        別名   メモ
claude      team        cct    会社アカウント
claude      personal    ccm    個人アカウント
```

- **名前**: プロファイルのディレクトリ名になります。半角英数推奨。
- **別名**: 短いコマンド。`cct` と打つとそのアカウントで直接起動します。省略可。
- 今使っている `~/.claude` のアカウントは書きません。常に 0 番「기본（デフォルト）」として出ます。

行数がそのままアカウント数です。

### 2. 作る

```bash
ccp-sync
```

TSV のとおりにプロファイルのディレクトリを作ります。

### 3. アカウントごとに一度ログイン

```bash
ccp
```

メニューでアカウントを選ぶと、そのアカウントで Claude Code が開きます。最初はログインしていないと表示されるので、
そこで `/login` します。アカウントの数だけ繰り返します。

## 使い方

| こう打つと | こうなる |
|---|---|
| `ccp` | メニューが出る。矢印キーで選んで Enter。**Enter だけならおすすめアカウント** |
| `ccp team` または `cct` | そのアカウントで直接 |
| `ccp team -c` | そのアカウントで **直前の会話を続ける**。上限に達して移るときはこれ |
| `ccp-usage` | メニューなしで残り枠だけ確認 |
| `ccp-ls` | どこに誰がログインしているか |
| `ccp-new 名前 別名` | アカウントをもう一つ |
| `ccp-edit 名前 新しい名前 新しい別名` | 名前・別名の変更。フォルダも移すのでログインは維持 |
| `ccp-rm 名前` | アカウント削除。そのログインだけ消え、履歴は残る |

メニューでは `↑↓`（または `j` `k`）で移動、数字を押すとその番号へ、`v` でグラフと表を切り替え、`q` で抜けます。
メニュー内で管理もできます。`a` で追加、選んだ行で `e` は名前・別名の変更、`d` は削除。いくつか質問に答えるとメニューに戻ります。

Claude Code 下部のステータス行には、現在のアカウントと残り枠が常に表示されます。

```
team:me@example.com │ Opus │ 주 ██░░┃░ 38%  5h █░░░┃░ 12%  Fable ███┃░░ 47% │ ~/proj │ ctx 12% │ git main
```

`주` は週間枠、`5h` は5時間枠です（`labels = full` で 주간 · 세션 と長く表示）。棒の中の `┃` はその枠での現在位置で、右端に近いほどリセットが近く、棒が `┃` に届かなければペース以下です（ccp メニューと同じ読み方）。70% から黄色、90% から赤になります。
リセットまでの時間も文字で見たいなら `statusline.conf` で `show_reset = yes`。
週間・セッションは Claude Code が直接渡す値です。Fable のような **モデル専用の週間枠** はステータス行に渡されないため、
ccp が `/usage` で取得した値をキャッシュして `Fable ██░░░ 47%` のように続けて表示します。10分ごとにバックグラウンドで更新し、古い値には `~` が付きます。

## よくある質問

**切り替えると会話は消えますか？**
消えません。履歴・設定・スキルは全アカウントで共有され、ログインだけが異なります。
上限に達したら別のアカウントで `ccp team -c` すれば同じ会話を続けられます。これが主な用途です。

**枠を確認するときにクレジットやトークンを消費しますか？**
しません。3つの経路のどれもモデルを呼びません。
- ステータス行: Claude Code がステータス行スクリプトに渡す `rate_limits` の値を読むだけです。リクエスト自体がありません。
- メニューの Claude アカウント: `claude -p /usage` を実行します。`/usage` は使用量 API を照会する内蔵コマンドで、モデルには何も送りません。
  JSON 出力で確認すると、モデルターン 0、費用 0 USD、入出力トークン 0 です。
- メニューの Codex アカウント: `codex app-server` にアカウントと上限の読み取り要求を送るだけです。
メニューが出るまでの数秒はネットワーク往復の時間で、枠には反映されません。

**アカウントを増やす・減らす・名前を変えたい。**
三つの方法があり、結果は同じです。
- メニュー内: `ccp` → `a` で追加、行を選んで `e` で編集、`d` で削除。
- コマンド: `ccp-new 名前 別名`、`ccp-edit 名前 新しい名前 新しい別名`、`ccp-rm 名前`。
- ファイル: `~/.config/ccp/profiles.tsv` を編集して `ccp-sync`。消した行のフォルダは `ccp-rm` か `rm -rf ~/.claude-profiles/名前`。
削除してもそのアカウントのログインだけが消え、履歴・設定は残ります。0 番のデフォルトは削除も改名もできません。

**いつも `--dangerously-skip-permissions` で起動しています。**
`~/.config/ccp/config.zsh` でこの行のコメントを外します。何を無効にするフラグか理解した上で。
```zsh
CCP_CLAUDE_ARGS=(--dangerously-skip-permissions)
```

**Codex も使っています。**
`codex` コマンドがあればメニューに自動で出ます。Codex アカウントを複数持つなら、
ツール列に `codex` と書いてください。Codex のプロファイルは **ワークスペース単位** です。個人用とチーム用、チームが複数ならチームごとに
プロファイルを作り、それぞれで `CODEX_HOME=~/.codex-profiles/名前 codex login` するときブラウザの承認画面でそのワークスペースを選びます。
同じ ChatGPT アカウントでもワークスペースごとに枠は別です。インストール時に `~/.codex/config.toml` の `[tui] status_line` に
**モデル・5時間枠・週間枠・コンテキスト** を入れるので、Codex の画面下にも表示されます（既に設定があれば触りません）。項目は Codex 内の
`/statusline` で変えられます。Codex は外部スクリプトをステータス行に付けられないため、ccp のプロファイル名はそこに出せません。
どのアカウントかは ccp メニューで確認します。Codex はワークスペース名を返さないので、メニューにはプロファイル名と
プラン（pro/team）だけが出ます。二つのプロファイルでメール・プラン・使用率が同じなら同じワークスペースにログインしています。
片方で `codex login` をやり直して別のワークスペースを選んでください。例: `codex	work	cxw	会社ワークスペース`

**メニューが出るまで数秒かかります。**
アカウントごとの残り枠を照会している時間です。1アカウント約3秒、並列実行なので全体もそのくらいです。上に書いたとおりクレジットは消費しません。

**メニューの言語を変えたい。**
メニュー・メッセージ・ステータス行は 日本語、English、한국어、中文 に対応しています。既定は端末のロケール（`LANG`）に従い、
`~/.config/ccp/config.zsh` に `CCP_LANG=ja` と書けば固定できます。一度だけなら `CCP_LANG=en ccp`。

**ステータス行の見え方を変えたい。**
`~/.config/ccp/statusline.conf` で決めます。表示する要素と順序、区切り、棒の幅と文字、使用率/残り率、色の基準、アカウントの書式。
編集しながら `ccp-statusline` でプレビューできます。例:
```
segments = account weekly session      # 枠だけ。モデル・ディレクトリ・git なし
bar = 0                                # 棒なしで数字だけ
percent = left                         # 残り率で
account = "{profile}"                  # メールを隠す
format = "{account} · {weekly} · {session} ▏{dir}"   # 順序の代わりにテンプレート
```
まったく別のものにしたければ `~/.config/ccp/statusline.sh` を作ると、それが代わりに実行されます。

**既存のステータス行があります。**
`install.sh --no-statusline` でインストールすれば触りません。

**新しいアカウントで MCP サーバーが見えません。**
MCP 設定は各アカウントの `.claude.json` にあります。そのアカウントで起動した状態で `claude mcp add --scope user …` をやり直します。

## トラブルシューティング

- `ccp` がないと言われる → 新しいターミナルを開くか `source ~/.zshrc`
