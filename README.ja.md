# ccp

こんにちは。ccp は、Claude Code のアカウントをいくつも使い回すのに疲れて作った小さなツールです。

会社アカウントで作業に没頭していたら上限に達してしまい、個人アカウントに移りたい。
でも `/logout` して `/login` してブラウザで承認して……とやっているうちに、会話の流れが切れてしまう。
そこで、**アカウントを切り替えても会話はそのまま続き、どのアカウントにどれだけ残っているかが一目で分かる** ものを作りました。

```
  Claude
  ── 今使える ─────────────────────────────────────────
  ▸ 2) team       ← おすすめ · 週間 62% 残り · 2日後にリセット
    0) 기본       週間 85% 残り · 5日後にリセット
  ── 今は使えない · セッション枠が空けば復活 ───────────
    1) personal   ⏳ セッション上限 — 2時間12分後に復活
```

`ccp` と打つとこの画面が出て、Enter を押すだけで今いちばん余裕のあるアカウントで起動します。
Codex CLI を使っているなら、そのアカウントも同じ画面に並びます。

> 正直に一つ。メニューの文字は今のところ韓国語です。以下のコマンドはどのロケールでも同じように動きます。

## はじめ方

必要なものは三つ。macOS か Linux、zsh（macOS は標準）、そしてすでに使っている Claude Code。
python3 も要りますが macOS には入っています。

ターミナルにこの三行を貼り付けてください。

```bash
git clone https://github.com/ssimu/ccp.git ~/projects/ccp
~/projects/ccp/install.sh
source ~/.zshrc
```

インストーラーがやるのは `~/.zshrc` に一行足して設定ファイルを作るだけなので、何度実行しても大丈夫です。
ログイン情報はどこにもコピーしません。それはこのあと自分でやります。

### 1. 自分のアカウントを書く

`~/.config/ccp/profiles.tsv` を開いてください。例が入っているので、自分のものに書き換えます。
1行が1アカウント、列は **タブ** で区切ります。

```
# ツール     名前        別名   メモ
claude      team        cct    会社アカウント
claude      personal    ccm    個人アカウント
```

- **名前** は自分が分かればなんでも。半角英数が楽です。
- **別名** は短いコマンド。`cct` と打つとそのアカウントで直接起動します。面倒なら空欄で。
- 今使っている `~/.claude` のアカウントは書きません。いつも 0 番「기본（デフォルト）」として出ます。

アカウントが2つでも5つでも、行数を合わせるだけです。

### 2. 作る

```bash
ccp-sync
```

書いたとおりにアカウントのフォルダを作ってくれます。

### 3. アカウントごとに一度ログイン

```bash
ccp
```

メニューでアカウントを選ぶと、そのアカウントで Claude Code が開きます。最初は「ログインしていない」と言われるので、
そこで `/login` してください。アカウントの数だけ繰り返せば準備完了です。

## ふだんの使い方

| こう打つと | こうなる |
|---|---|
| `ccp` | メニューが出る。矢印キーで選んで Enter。**Enter だけならおすすめアカウント** |
| `ccp team` または `cct` | そのアカウントで直接 |
| `ccp team -c` | そのアカウントで **直前の会話を続ける**。上限に達して移るときはこれ |
| `ccp-usage` | メニューなしで残り枠だけ覗く |
| `ccp-ls` | どこに誰がログインしているか |
| `ccp-new 名前 別名` | アカウントをもう一つ |

メニューでは `↑↓`（または `j` `k`）で移動、数字を押すとその番号へ、`v` でグラフと表を切り替え、`q` で抜けます。

そして Claude Code の画面下のステータス行に、今どのアカウントで、どれだけ残っているかが常に出ています。

```
team:me@example.com │ 주간 ██░░░ 38% ↻2일3시간 │ 세션 █░░░░ 12% ↻1시간40분 │ Opus │ ~/proj │ ctx 12% │ git main
```

`주간` は週間枠、`세션` は5時間枠、`↻` はリセットまでの時間です。70% を超えると黄色、90% で赤になるので、ちらっと見れば十分です。

## よく聞かれること

**切り替えると会話は消えますか？**
消えません。履歴・設定・スキルはすべてのアカウントで同じものを見ています。違うのはログインだけ。
だから上限に達したら別のアカウントで `ccp team -c` すれば、そのまま続きから。これがこのツールを作った理由です。

**アカウントを増やしたい／減らしたい。**
`profiles.tsv` の行を足すか消して `ccp-sync`。消したアカウントのフォルダも片付けるなら `rm -rf ~/.claude-profiles/名前`。
そのアカウントのログインだけが消え、履歴は残ります。

**いつも `--dangerously-skip-permissions` で起動しています。**
`~/.config/ccp/config.zsh` を開いてこの行のコメントを外してください。意味が分かる人だけ。
```zsh
CCP_CLAUDE_ARGS=(--dangerously-skip-permissions)
```

**Codex も使っています。**
`codex` コマンドがあればメニューに自動で出ます。Codex アカウントを複数持つなら、
ツール列に `codex` と書いてください。例: `codex	work	cxw	会社ワークスペース`

**メニューが出るまで数秒かかります。**
各アカウントに「どれだけ残ってる？」と聞いている時間です。1アカウント約3秒ですが同時に聞くので全体もそのくらい。
モデルを呼ぶわけではないのでトークンは使いません。

**もともと使っているステータス行があります。**
`install.sh --no-statusline` でインストールすれば、ステータス行には触りません。

**新しいアカウントで MCP サーバーが見えません。**
MCP 設定はアカウントごとです。そのアカウントで起動した状態で `claude mcp add --scope user …` をもう一度。

## うまくいかないとき

- `ccp` がないと言われる → 新しいターミナルを開くか `source ~/.zshrc`
- メニューに自分のアカウントが出ない → `ccp-sync` を忘れています
- 「미로그인（未ログイン）」と出る → `ccp 名前` で開いて `/login`
- 別名が効かない → `cp` のように既存のコマンドと同じ名前です。ターミナル起動時に警告が出ます。別の名前に
- それでもだめなら → このリポジトリに issue を。何を打って何が返ってきたかを添えて
